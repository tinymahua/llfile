# Easel Manager · WorkBuddy 设计稿提示词档案

> 用途：给 WorkBuddy（AI 设计稿生成工具）使用。每页一份提示词，直接粘贴即可出稿。
> 目标：为 **Easel 桌面管理器**（嵌入 fr-llfile 的工具场景）生成 UI 设计稿。
> 数据来源：基于已确认的 M0a 阶段界面规划（详见 `Easel/docs/desktop-shell-roadmap.md` 第六节）。共 3 页 + 4 态对比。

---

## 统一设计基底（所有页面共用）

- **桌面端 1440×900**，fr-llfile 主窗口默认尺寸；嵌入 fr-llfile 侧栏 + 主面板的二级场景页
- **目标用户**：开发者 / 技术用户，能读懂端口号 / 路径 / 版本号
- **背景**：fr-llfile 主灰 `#F5F5F5`（主面板）+ 面板白 `#FFFFFF`（卡片）
- **品牌色**：绿萝绿 `#1F9D7A`（与 fr-llfile 主色一致）
- **状态色**：
  - 绿 `#79c97e`（ready / pass）
  - 黄 `#d4a548`（warning / loose verify）
  - 红 `#d65a5a`（error）
  - 灰 `#888888`（unknown / M0a 占位未启用）
- **卡片**：白底圆角 12-16，轻阴影 `0 1px 4px rgba(0,0,0,0.08)`；分隔用 1px `#EEE`
- **字体**：sans-serif（与 fr-llfile 一致）
  - 正文 14px / 标题 16-18px / 主操作 14-16px/600
  - 检测值/版本/路径统一使用等宽字体（JetBrains Mono 或系统等宽）
- **图标**：线性 + 实心混搭，统一 16px / 20px 两档（沿用 fr-llfile settings 页图标集）
- **间距**：8 / 16 / 24 px 栅格
- **可达性**：主操作按钮 ≥ 36px 高，状态徽章点击区 ≥ 24px，hover 时有微反馈（透明度 0.85 或下划线）
- **禁用态规范**：所有"未启用"按钮统一浅灰底 `#F5F5F5` + 文字 `#CCC`，**禁止用半透明颜色模拟禁用**（避免与"启用但弱化"混淆）

## 1. 项目根选择对话框（未注册态全屏覆盖）

**桌面端 1440×900 · fr-llfile - Easel 场景页 - 项目根选择对话框（未注册态）**

请设计一张完整稿。背景为 fr-llfile 主面板（浅灰 + 简单导航骨架示意），上方覆盖一层半透明遮罩，遮罩中央悬浮对话框。

### 页面结构（自上而下）

1. **背景层（fr-llfile 主面板，示意即可）**
   - 左侧侧栏（200px 宽，深灰底 `#2C2C2E`，列出 4-5 个工具场景图标，其中"Easel"项灰显且带角标小提示"未配置"）
   - 右侧主面板（空，内容区用浅灰块示意，不画细节）
   - 整个背景被半透明黑 `rgba(0,0,0,0.25)` 覆盖

2. **对话框容器**（居中悬浮，宽 720px，高 560px，白底圆角 16，阴影 `0 8px 32px rgba(0,0,0,0.16)`）

3. **标题栏**（高 56px，含 1px `#EEE` 底边框）
   - 左侧 padding 24px：标题"选择 Easel 项目根"（18px/600 `#1A1A1A`）
   - 右侧 padding 24px：× 关闭按钮（28×28，浅灰 `#999`，hover `#666`）

4. **Tab 栏**（高 48px，含 1px `#EEE` 底边框）
   - 三个 tab 横排，左侧 padding 24px 起，tab 间间距 24px
   - **Tab 1**："手动"（选中态：底部 2px 绿萝绿下划线 + 文字 `#1F9D7A`）
   - **Tab 2**："自动发现"
   - **Tab 3**："openclaw 反推"
   - tab 文字 14px/500，未选态 `#666`

5. **Tab 内容区**（padding 24px，高度自适应，剩余填充至底部 72px 操作栏）

   #### Tab 1 · 手动（默认选中）
   - 中部居中布局：
     - 按钮"选择文件夹..."（高 40px，宽 160px，绿萝绿底白字，圆角 8，14px/600）
     - 按钮下方间距 16px
     - 已选路径预览区（白底浅灰边框 1px `#EEE`，圆角 8，内 padding 12px，等宽字体 14px `#1A1A1A`）
     - 未选时显示浅灰占位文字"尚未选择"（14px/500 `#999`）

   #### Tab 2 · 自动发现
   - 顶部副标题"在系统盘扫描到以下候选"（12px/500 `#666`，左对齐 padding 0）
   - 候选列表（最多 6 项可见，超出滚动；高度自适应）：
     - 每行高 56px，白底，下边线 1px `#EEE`
     - 左侧 padding 16px：路径文本（14px 等宽 `#1A1A1A`）
     - 中右：项目名猜测（12px `#999`，第二行）
     - 右侧 padding 16px：健康徽标组（小圆点 8px + 文字 12px）
       - 绿点 + "含 venv + easel 包" / 黄点 + "含 venv 缺包" / 灰点 + "仅命中特征"
     - 选中态：行背景 `#F0FAF6` + 左侧 3px 绿萝绿边条
     - 未选：行背景白
   - 空态：列表区居中显示"未在系统盘扫到含 `.venv` 且安装 `easel` 包的目录"（14px/500 `#999`）

   #### Tab 3 · openclaw 反推
   - 顶部副标题"从 openclaw 状态反推的候选"（12px/500 `#666`）
   - 候选列表（同 Tab 2 结构）
   - 行额外字段：最右侧灰字 10px/300 等宽显示"来自 `<openclaw 状态路径>`"
   - 空态："未发现 openclaw 状态目录，先用「手动」或「自动发现」选择"（14px `#999`）

6. **底部操作栏**（高 72px，含 1px `#EEE` 顶边框，右对齐 padding 24px）
   - 「取消」按钮（高 36px，宽 88px，白底浅灰边框 1px `#DDD`，圆角 8，14px/500 `#666`）
   - 「确定」按钮（高 36px，宽 88px，圆角 8，14px/600）
     - **未选候选时**：背景 `#CCC` 文字 `#FFF`（禁用态规范）
     - **已选候选时**：背景绿萝绿 `#1F9D7A` 文字白

### 输出要求

- 一次生成 3 个 tab 各一张完整稿，标注"Tab 1/2/3"
- Tab 1 与 Tab 2 至少各展示 1 行候选被选中的态（验证选中态视觉）
- Tab 2 与 Tab 3 同时附"空态"小图（仅列表区内容替换为居中提示文字）

## 2. Easel Scene 主面板（已注册态）

**桌面端 1440×900 · fr-llfile - Easel 场景页 - 主面板（已注册态）**

请设计一张完整稿（ready 态基线）+ 3 张状态切换对比小图（clean / integrated / error）。4 张共享同一布局骨架，仅状态卡视觉、检测清单展开状态、错误条目展示有差异。

### 页面结构（自上而下，三个折叠区）

#### A. 状态卡（顶部 120px，常驻可见）

- 高度 120px，距顶部 24px，左右各 24px padding（即充满主面板宽度减 48px 边距）
- 白底圆角 12，阴影 `0 1px 4px rgba(0,0,0,0.08)`
- 内部分左右两栏，padding 24px：

  **左栏**（占 70%）
  - **顶行**（高 24px）：
    - 状态圆点（12px 实心圆，按状态着色）+ 状态名（18px/600 `#1A1A1A`，与圆点同行左对齐 8px 间距）
    - 同行右侧靠右：小字"· 最后扫描：14 秒前"（12px `#999`）
  - **中行**（高 40px，距顶行 12px）：
    - 版本摘要（14px `#1A1A1A` 等宽字体）格式示例：
      `"Python 3.12.4 · openclaw 2026.9.x · 端口 7860 · gateway PID 12345"`
  - **底行**（仅 error 态显示，高 24px，距中行 8px）：
    - 红色小三角警示图标（14px）+ 错误摘要（12px `#d65a5a`），例："✗ 检测到 openclaw 端口冲突"

  **右栏**（占 30%，右对齐，距左栏 24px）
  - **主操作按钮**（高 36px，宽 140px，圆角 8，14px/600 / 状态卡右上角）：
    - ready 态：「打开工作台」—— 背景 `#F5F5F5` 文字 `#CCC`（**M2 启用占位，灰显**）
    - clean 态：「开始安装」—— 背景 `#F5F5F5` 文字 `#CCC`（**M3 启用占位，灰显**）
    - integrated 态：「打开工作台」—— 背景绿萝绿 `#1F9D7A` 文字白（M2 已实现态）
    - error 态：「查看诊断」—— 背景 `#F5F5F5` 文字 `#CCC`（**M1 启用占位，灰显**）
    - hover 时所有灰显按钮显示 tooltip 提示对应 M 阶段（如"M2 启用"）
  - **次按钮**（高 32px，宽 88px，白底浅灰边框 1px `#DDD`，14px/500 `#666`，置于主按钮下方 8px，右对齐）：
    - 「↻ 重新扫描」+ 旁边 24×24 圆点图标按钮"⋯"（点击展开下拉菜单：移除此项目 / 在文件管理器中打开项目根 / 复制状态摘要）

#### B. 检测清单（A/B/C 合并，折叠列表）

- 距状态卡上方 16px（间距）
- 自适应高度，默认仅展开失败项所在的折叠组，其它折叠
- 4 个折叠组，垂直堆叠，每组间 16px 间距：

  **折叠组 1 · Python 环境**
  - 标题栏（高 40px）："Python 环境"（16px/600 `#1A1A1A`，左侧 padding 24px）+ 右侧展开/折叠箭头（16px `#999`）
  - 展开后行内容：
    - Python 解释器（venv 内）：版本 / 路径 / `--version` 解析结果
    - pip 可执行包数：`pip list | wc -l`（loose verify）
    - winget 可用性（仅 Windows，M3 才有的 MCP）

  **折叠组 2 · openclaw**（A + C）
  - `openclaw.cmd` 路径存在性
  - `--version` 解析
  - gateway 进程 PID（仅显示是否在跑，不显示控制按钮，M2 才管）
  - 状态目录：静态路径（首次扫描时冻结）

  **折叠组 3 · Easel 包**（A）
  - `easel` 包导入：`python -c "import easel"`
  - 已注册命令清单：`python -m easel --help` 解析
  - 步骤注册表存在性（M0a 不渲染步骤列表，只 flag "available / not yet"）

  **折叠组 4 · 端口与工作区**（A + C）
  - :7860 占用方（loose verify = `Test-NetConnection` 5s 超时）
  - :18789 同上
  - `EASEL_OPENCLAW_STATE_DIR` / `EASEL_OPENCLAW_WORKSPACE` 路径（标"动态值"提示用户实际路径由运行时决定）

- **每行结构**（高 40px，下边线 1px `#F5F5F5`，padding 24px 16px）：
  - 名称（14px/500 `#1A1A1A`，宽 24px 标签左对齐）
  - 状态徽章（小圆点 8px + 文字 12px）
  - 当前值（等宽字体 14px `#1A1A1A`，主内容区）
  - "?" 图标（16px 浅灰 `#999`，hover 显示 tooltip："检测来源 A/B/C + 命令字符串"）

#### C. 最近活动 / 错误面板（折叠区，可隐藏）

- 距检测清单上方 16px
- 折叠标题栏（高 40px，白底圆角 12，阴影同 A）：
  - "最近活动"（16px/600 `#1A1A1A`，左侧 padding 24px）
  - 右侧：红色徽章（20×20 圆，红底 `#d65a5a` 白字，居中显示未读条数 N）+ 展开/折叠箭头
- 默认折叠，展开后内容（与 B 区行结构一致）：
  - 上次扫描的失败条目（直接复述 B 区里红点的条目）
  - 当前 `install-state.json` 里未完成步骤计数（即便 M0a 没步骤注册表，也保留这条占位以验证状态文件机制）

### 4 种状态视觉变体

| 状态 | 状态卡圆点 | 状态名 | 主按钮 | 主按钮色 | 检测清单默认展开 | 错误面板 |
|---|---|---|---|---|---|---|
| `clean`（有项目根，未装） | 灰 `#888` | "未安装" | "开始安装" | 灰显 `#F5F5F5`/`#CCC`（M3 占位） | 仅展开缺包条目所在组 | 折叠，徽章 N |
| `ready`（有项目根，已装） | 绿 `#79c97e` | "就绪" | "打开工作台" | 灰显 `#F5F5F5`/`#CCC`（M2 占位） | 全部折叠 | 折叠，徽章 0 |
| `integrated`（M2+ 才有） | 绿 `#79c97e` 脉冲 | "运行中" | "打开工作台" | 绿萝绿 `#1F9D7A`/白 | 全部折叠 | 折叠，徽章 0 |
| `error`（扫描失败） | 红 `#d65a5a` | "故障" | "查看诊断" | 灰显 `#F5F5F5`/`#CCC`（M1 占位） | 自动展开失败条目 | 自动展开，徽章 N |

### 输出要求

- 一次生成 1 张完整主面板稿（ready 态作为基线）
- 附加 1 张"4 状态对比图"：4 个 360×240 的小卡片（仅状态卡区），分别标注 4 个状态，圆点色 / 标题 / 主按钮文案颜色有差异，布局其余部分统一
- 提示：基线稿的右上角主按钮是灰显的"M2 启用"占位 —— 这是 M0a 关键克制

## 3. 移除项目确认对话框（二级 modal）

**桌面端 1440×900 · fr-llfile - Easel 场景页 - 移除项目确认对话框**

请设计一张完整稿。背景为已注册态主面板（用半透明遮罩覆盖，遮罩比对话框 1 更深），对话框居中悬浮。

### 页面结构

1. **背景层**：已注册态主面板（简化示意：状态卡 + 检测清单第一组展开），上层覆盖更深遮罩 `rgba(0,0,0,0.4)`，侧栏不被覆盖

2. **对话框容器**（居中悬浮，宽 480px，高 320px，白底圆角 16，阴影 `0 8px 32px rgba(0,0,0,0.16)`）

3. **标题区**（高 56px，含 padding 24px）
   - 标题"移除此 Easel 项目？"（18px/600 `#1A1A1A`，左对齐）
   - 右侧 × 关闭按钮（24×24，浅灰 `#999`）

4. **说明区**（padding 24px 16px）
   - 三条要点，每条高 28px：
       - **要点 1**：左侧绿萝绿圆点 8px + 文字"仅解除 fr-llfile 中的注册记录"（14px/500 `#1A1A1A`）
       - **要点 2**：左侧黄色圆点 12px（提示"不动"语义）+ 文字"不会卸载 Python / openclaw / 文件"（14px/500 `#1A1A1A`）

5. **项目根展示区**（距说明区 3px padding）

6. **底部操作栏**（高 64px，含 1px `#EEE` 顶边框，右对齐 padding 24px）
   - 「取消」按钮（高 36px，宽 88px，白底浅灰边框 1px `#DDD`，圆角 8，14px/500 `#666`）
   - 「移除注册」按钮（高 36px，宽 120px，红色 `#d65a5a` 底白字，圆角 8，14px/600）
   - 「移除注册」按钮 hover 时背景 `#c54a4a`

### 输出要求

- 生成 1 张完整稿
- 标注三条要点前的圆点颜色语义（绿/黄/灰）
